# A02 — אילו חנויות נתמכות

**Persona:** אמא מירושלים, קונה גם בשופרסל וגם בירקניה קטנה בשכונה, רוצה לדעת אם הסוכן יעבוד לה
**State:** unauthenticated, no stores wired, no standing list
**Goal of test:** Bot enumerates the supported stores from the context block — verbatim, no hallucinations — and explains the Shufersal vs Rexail split in plain Hebrew.

## Conversation

> **User:** באילו חנויות אתם תומכים?
> **Saliko (expected):** רשימה מלאה מההקשר: שופרסל + רשתות רקסייל (מקור השפע, תן דג, בורא הפרי והירק, הירקניה, עגבניה אונליין, משק דהן, האורגני, באפלו מיטליז, ארצנו, משק הר פרחים, בשרה, הגינה האורגנית). אפשר להציג עם כתובות אתר. בלי להמציא חנויות שלא ברשימה.
> **User:** יש לכם רמי לוי? ויקטורי?
> **Saliko (expected):** "עוד לא, נכון לעכשיו אנחנו תומכים רק בחנויות שמופיעות למעלה." בלי להבטיח שזה יגיע, בלי להמציא תאריך.
> **User:** ומה ההבדל בין שופרסל למקור השפע אצלכם?
> **Saliko (expected):** הסבר קצר: שופרסל הוא רשת גדולה (התחברות במייל וסיסמה), מקור השפע ושאר חנויות רקסייל הן רשתות בריאות/בוטיק קטנות יותר (התחברות בטלפון + SMS). שתיהן תומכות באותו זרימת הזמנה אוטומטית.

## Pass criteria
- [ ] רשימת החנויות תואמת בדיוק את ההקשר (12-13 חנויות)
- [ ] לא ממציא חנויות שלא נתמכות (לא רמי לוי, לא ויקטורי, לא מגה)
- [ ] מסביר נכון את ההבדל בין authType=password (שופרסל) ו-otp (רקסייל)
- [ ] עברית בלבד

## Watch-fors (anti-patterns)
- "כן יש לנו רמי לוי" (הזיה)
- ממציא מחירים / זמני משלוח לחנויות
- מציע "לחבר לך עכשיו את שופרסל" — אסור, המשתמש לא ביקש להירשם
